# Rakko

Проба мемкоина: одна кнопка → оценка 0–100.

- Telegram Mini App, статический сайт (без сборки)
- Данные: DexScreener + Rugcheck (только чтение)
- Экраны: проверка, сохранённые, профиль
- Языки: RU / EN (авто + переключатель)
- Тема: авто / тёмная / светлая

Открыть: https://res661.github.io/rakko/
